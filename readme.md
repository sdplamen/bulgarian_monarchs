# Bulgarian Monarchs

This project provides a historical guide to the rulers of Bulgaria throughout the centuries. It's a Django-based application that allows you to explore the lineage of Bulgarian monarchs, their periods of reign, and the capitals from which they governed.

## Features

*   **Find Monarch by Year:** Enter a year to discover which monarch was in power.
*   **Find Monarch by Name:** Search for a specific monarch by their name.
*   **Find Capital by Year:** Discover the capital of Bulgaria for a given year.
*   **API:** A RESTful API is available for programmatic access to the data.

## Technologies Used

*   **Backend:** Django, Django REST Framework
*   **Database:** SQLite (default)
